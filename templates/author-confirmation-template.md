## Use

Use this template only when author confirmation blocks safe progress or an authorization decision. Put brief, factual background before the confirmation block. Replace every placeholder with task-specific information, omit inapplicable optional fields, and never treat an empty answer or a recommended default as approval.

## Optional Alternatives Format

Use this form when the author must choose among defined alternatives. Keep choices at the same list level so the structure remains easy to scan and reply to.

1. **Question:** <Decision to make>
   - **Why it matters:** <Why the choice affects the work>
   - **Option A:** <First alternative>
   - **Option B:** <Second alternative>
   - **Recommended default:** <Optional option name and reason>
   - **Answer:** <Option A | Option B | Other: ...>

## Constraints

- Keep all independent confirmations in one ordered list under the confirmation heading.
- Use one top-level item per decision; do not nest lists beyond its supporting unordered list.
- Keep each question self-contained and make the required response explicit.
- Use a recommendation only when it is evidence-based and safe to decline.
