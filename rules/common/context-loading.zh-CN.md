# 上下文加载规则

> 语义源：英文 [Context Loading Rule](context-loading.md)。本文档为中文对应版本。

## 目的

为当前任务加载最小且可靠的必要上下文。不要将整个 Toolkit、整个仓库或所有可用文档视为默认上下文。

## 加载顺序

按以下顺序渐进式加载信息：

1. **启动**：识别目标仓库。阅读其入口说明、此 Toolkit 的架构以及适用于该任务的政策。
2. **角色和工作流**：仅当任务需要相应职责模型或多阶段流程时，加载活动角色和工作流。
3. **技能和模板**：加载所请求专业操作或输出所需的聚焦技能、模板或参考资料。
4. **项目上下文**：阅读相关的项目概览、架构、决策、任务细节、源文件、配置和测试。

## 选择规则

- 优先使用最具体、最权威且最新的可用来源。
- 在应用通用 Toolkit 指引前，阅读目标项目的明确说明。
- 仅在文档会影响所请求的决策、执行、验证或输出时加载该文档。
- 按需阅读引用材料；不要递归加载所有链接文档。
- 不要将模板、示例、归档材料或无关项目文件视为活动要求。

## 上下文不足时

说明缺失内容及其重要性。若相关来源可用则检查它；否则，在作出会扩大范围、改变所有权或导致不可逆操作的假设前请求澄清。
