# Toolkit Override Template

## Use

Use this project-local template only when a project must replace otherwise applicable Toolkit guidance. Store the completed record at a path explicitly routed by the project's `AGENTS.md`.

Each record defines an active project contract. Do not use it for a proposal, preference, or task status. It cannot override system, safety, or other higher-priority requirements.
