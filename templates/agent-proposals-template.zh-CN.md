# Agent 建议事项模板

> 语义源：英文 [Agent Proposals Template](agent-proposals-template.md)。本文档为中文对应版本。

## 使用方式

在私有开发状态仓库的 `projects/<project-id>/agent-proposals.md` 使用这一非权威模板。它记录尚未成为已授权工作的 Agent 生成建议。不得在产品仓库或 `max-ai-toolkit` 中放置副本。

当建议需要先作出决策才能安全推进时，使用[作者确认模板](author-confirmation-template.zh-CN.md)。
